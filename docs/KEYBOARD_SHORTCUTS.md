# Keyboard Shortcuts

## Main Window

### Session Controls
- `Ctrl+S` - Start Session
- `Ctrl+Shift+S` - Stop Session

### Navigation
- `Ctrl+B` - Open Session Browser
- `Ctrl+A` - Open Analysis Dashboard
- `Ctrl+C` - Open Session Comparison
- `Ctrl+,` - Open Settings

### Shot Table
- `Return` / `Enter` - Review selected shot
- `Delete` - Delete selected shot(s)
- `F` - Toggle favorite status (context menu)
- `T` - Edit tags (context menu)
- `N` - Edit notes (context menu)

## Shot Review Window

### Playback Controls
- `Space` - Play/Pause
- `S` - Stop and return to first frame
- `Left Arrow` - Rewind 10 frames
- `Right Arrow` - Forward 10 frames
- `Ctrl+Left Arrow` - Seek backward 30 frames
- `Ctrl+Right Arrow` - Seek forward 30 frames

### Speed Controls
- `1` - Set speed to 0.1x
- `2` - Set speed to 0.25x
- `3` - Set speed to 0.5x
- `4` - Set speed to 1x
- `5` - Set speed to 2x
- `6` - Set speed to 4x

### Drawing Tools
- `D` - Select Freehand tool
- `P` - Select Swing Plane tool
- `R` - Select Reference Line tool
- `E` - Select tool (for changing line colors)
- `C` - Clear all drawings
- `Ctrl+C` - Open color picker

### Shot Metadata
- `F` - Toggle favorite status
- `T` - Edit tags
- `N` - Edit notes
