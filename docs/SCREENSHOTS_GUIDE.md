# Screenshots Guide

## Required Screenshots

To complete the documentation, capture the following screenshots:

### 1. Main Window (`docs/screenshots/main_window.png`)
**What to capture:**
- Main application window with dual camera previews (DTL and Face-on)
- Session controls (session name, club selector, start button)
- Shot table with thumbnails
- Status bar showing connection status

**How to capture:**
1. Start ProMirrorGolf
2. Start a session with cameras running
3. Take a test shot or have a few shots in the table
4. Capture the full window (1920x1080 or similar)

### 2. Shot Review Window (`docs/screenshots/shot_review.png`)
**What to capture:**
- Dual video playback (DTL and Face-on side-by-side)
- Drawing tools visible (toolbar with freehand, swing plane, etc.)
- Timeline scrubber with markers
- Playback controls
- Shot data overlay visible

**How to capture:**
1. Double-click a shot with video
2. Draw a line or annotation on the video
3. Capture the full shot review window

### 3. Analysis Dashboard (`docs/screenshots/analysis_dashboard.png`)
**What to capture:**
- Analysis dashboard with multiple charts visible
- Speed trends chart
- Dispersion plot
- Summary statistics
- Period/club filters visible

**How to capture:**
1. Click "Analysis" button
2. Select a time period with data
3. Ensure multiple charts are visible
4. Capture the full dashboard

### 4. Web Dashboard (`docs/screenshots/web_dashboard.png`)
**What to capture:**
- Web dashboard in browser
- Interactive charts visible
- Statistics panel
- Responsive layout

**How to capture:**
1. Start ProMirrorGolf (web server runs automatically)
2. Open http://127.0.0.1:5000 in browser
3. Capture the browser window showing the dashboard

## Screenshot Specifications

- **Format:** PNG
- **Resolution:** Minimum 1920x1080 (or window size)
- **File size:** Keep under 500KB (compress if needed)
- **Naming:** Use exact filenames listed above
- **Location:** Save to `docs/screenshots/` directory

## Tips

- Use Windows Snipping Tool or Print Screen
- Ensure UI is clean (no personal data visible)
- Show the app in a good state (with data, not empty)
- Consider using a dark background for consistency
- Crop to remove unnecessary browser/OS chrome
